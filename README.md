# EcoTech Solutions - Módulo 6

Repositorio con los tres ejercicios, uno por carpeta.

## Ejercicio 1 - Sanitización y análisis de sensores
```bash
cd ejercicio_1
python ejercicio_1.py
```

## Ejercicio 2 - Productos, excepciones y persistencia
```bash
cd ejercicio_2
python ejercicio_2.py
```
Genera el archivo `catalogo_ecotech.json`.

## Ejercicio 3 - Tests unitarios e integración con Django
```bash
cd ejercicio_3
pip install -r requirements.txt
python manage.py test          # corre los tests unitarios
python manage.py runserver     # levanta el panel
```
Abrir http://127.0.0.1:8000/ en el navegador.
